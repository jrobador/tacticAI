# tacticAI Match Engine

A 3D football match simulation engine used offline to generate synthetic matches (video and tracking data) for tacticAI. It is built as a Python extension module named `_tai_engine`.

Build it with the Dockerfile in this directory: `docker build -t tai-engine .`. At runtime the engine reads two environment variables: `TAI_DATA_DIR` (path to the `data/` directory) and `TAI_FONT` (path to the `.ttf` font file). The Dockerfile sets both.
