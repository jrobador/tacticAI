# tacticAI

tacticAI is AI match intelligence built from synthetic football events, created for the Microsoft Premier League Hackathon "Inside the Game". It simulates matches, turns them into structured data, and builds statistics, explanations and on-screen insight on top.

## Pipeline

| Stage | Context |
| --- | --- | --- |
| 1 | Ingest: synthetic match factory (video, tracking, events) | 
| 2 | Interpret: statistics, patterns and context | 
| 3 | Explain: why moments matter | 
| 4 | Render: on-screen insight synchronized to the video | 
| 5 | Personalize: analyst vs casual fan, favorite club/player, language |


## Quickstart (Stage 1)

Build the engine image (once):

```
docker build -t tai-engine engine
```

Generate a match (the engine runs only inside Docker; `xvfb-run` must be wrapped in `sh -c`, it hangs as PID 1):

```
docker run --rm -v C:\Github\tacticAI:/work -e PYTHONPATH=/engine:/work/src tai-engine sh -c "xvfb-run -a -s '-screen 0 1280x720x24' python3 -m tacticai.ingest generate --seed N --out /work/data/matches"
```

Infer events on the host (stdlib only):

```
set PYTHONPATH=src
python -m tacticai.ingest events data/matches/match_N
```

On Linux/macOS use `PYTHONPATH=src python -m tacticai.ingest events data/matches/match_N`. Run the tests with `python -m pytest tests`.

## Repo map

- `src/tacticai/ingest/`: Stage 1 (domain, application, infrastructure, interfaces). The other stages are placeholders.
- `engine/`: the C++ match engine and its Docker build.
- `docs/`: architecture and the Ingest engine reference.
- `data/matches/`: generated matches (git-ignored).
- `tests/`: pytest tests.
